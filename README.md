# ЛБ №4 — Графічний інтерфейс на PyQt6

Файли відповідають завданням лабораторної роботи:

| Файл | Завдання |
|------|----------|
| `task1_widgets.py` | 1. Віджети та layouts |
| `task2_form.py` | 2. Форма: сигнали/слоти, валідація, скидання |
| `task3_mainwindow.py` | 3. QMainWindow: меню, toolbar, statusBar, shortcuts |
| `task4_custom_signals.py` | 4. Кастомні сигнали, disconnect / blockSignals |
| `task5_dialogs_qss.py` | 5. Діалоги та QSS |

## Запуск
```bash
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python task1_widgets.py
```
